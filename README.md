gologdb_brmodelo é a estrutura do modelo de banco de dados do sistema GoLog, incluindo as entidades, atributos, relacionamentos.

As tabelas e relacionamentos foram estruturados para otimizar o mapeamento relacional, consistência e performance no SGBD.

Conteúdo do Ficheiro:
Introdução: Contexto sobre a modelagem e projeto da GoLogAPI.

Entidades Principais:

tb_delivery: Tabela central de entregas.

tb_user: Tabela de utilizadores/operadores.

tb_delivery_type: Classificações de entregas.

tb_transport e tb_type_transport: Gestão de frotas.

tb_address: Tabela de endereços de origem e destino.

tb_company: Tabela de clientes/empresas associadas.

tb_equipament; Tabela de equipamentos/veiculos

tb_group_equipament: Tabela de conjunto de equipamentos

...

Relacionamentos e Cardinalidade: Definição da integridade referencial entre as tabelas.
